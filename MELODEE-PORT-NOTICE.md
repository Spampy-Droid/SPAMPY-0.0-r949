# Source provenance

This firmware derives from the user's Spampy r918, itself based on SLOOP 2.7.1. Its hardware PC guard correction is retained.

Melodee 1.4.1 native Prophet, SID and CZ integration source is credited to Kerem Kilic (Ellic Studio). Existing copyright notices remain in the imported source files. Native CZ synthesis includes Devin Acker's BSD-3-Clause uPD933 model; the complete notice is in LICENSES/BSD-3-Clause-uPD933.txt. Existing SLOOP, msfa and other upstream notices remain applicable.

The CZ sine constants reproduce exactly Melodee's integer-recurrence table initialization, stored as constant float values to avoid introducing a separate runtime initializer. Selected CZ patches preserve the original 144-byte tones. SID retains native 6581/8580 single-waveform synthesis for the two requested patches; combined-waveform caches and C64 player modes are excluded. Prophet data preserve the original program records, with INIT generated by the original initializer. BELL/PAD use the original FM6 patch bytes on Spampy's existing FM6 engine.

No full Melodee editor or SysEx bank-management UI is included. The bank selection remains persistent through ordinary Spampy projects and engine macro parameters.
