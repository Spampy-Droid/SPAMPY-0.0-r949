# SPAMPY 0.0 — r949

Custom M-VAVE FM-1 firmware based on Felucca/Sloop, with a synthwave-inspired interface, sound tools, scenes, drum processing, effects, and games.

## r949

This release centers the `PAUSED` and `PLAY TO RESUME` messages in Neon Pang and Neon Bubbles. No other gameplay, sound engine, preset, effect, or interface function was changed.
